# Índice de memoria operacional de agentes

Esta carpeta guarda **índices operacionales** para el trabajo de agentes. **No** es fuente de verdad superior a `docs/`.

## Reglas
- Entradas **breves, durables y enlazadas** a los docs canónicos.
- **No** guardar secretos, credenciales, cookies, material externo crudo ni perfiles psicológicos de personas.
- Prefiere **actualizar** una nota existente antes que duplicar.
- Si una nota cambia el contexto durable del proyecto, actualiza `docs/CONTEXT_PACK.md` y `docs/DECISION_LOG.md`.

## Referencias canónicas
- `docs/CONTEXT_PACK.md`
- `docs/DECISION_LOG.md`
- `docs/MAINTENANCE_CHECKLIST.md`
