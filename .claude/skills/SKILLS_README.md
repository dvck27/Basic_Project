# Skills (wrappers Claude Code)

Estos son **wrappers de compatibilidad** para Claude Code. La **fuente canónica y agnóstica** de cada skill vive en
`docs/agent_factory/skills/<nombre>/SKILL.md`. Aquí solo se añade `allowed-tools` y un resumen ejecutable.

Regla: si editas una skill, hazlo primero en la canónica y resincroniza el wrapper (skill `repo-change-sync`).

`repo-primer`, `memory-manager`, `readme-maintainer`, `context-pack-maintainer`, `decision-log`,
`documentation-sync`, `prp`, `phased-implementation`, `sprint`, `codebase-analyst`, `quality-gates`,
`security-ingestion`, `repo-change-sync`, `rescue-context`, `skill-creator`, `postmortem-learning`.
